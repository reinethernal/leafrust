Для решения вашей задачи одной классической нейросети (которая просто выдает название болезни) будет недостаточно, так как вам нужно одновременно распознать тип болезни и рассчитать процент поражения (Severity Estimation). [1] 
Готового «коробочного» решения в один клик под обе задачи сразу нет, но эта проблема эффективно решается комбинацией двух моделей или использованием мультизадачных архитектур.
Ниже приведены лучшие готовые архитектуры, подходы и наборы данных для реализации такой системы.
------------------------------
## 1. Готовые архитектуры моделей (Что выбрать)## Вариант А: Сегментация + Классификация (Самый точный подход)
Вы разделяете задачу на два этапа с помощью двух разных нейросетей:

   1. Определение площади и процента заражения: Используется модель семантической сегментации, например, YOLOv8-seg или Mask R-CNN. Вы обучаете её выделять маской две зоны: «весь лист» и «пятна/поражения».
   * Как считать процент: Программа считает количество пикселей в маске болезни, делит на количество пикселей маски всего листа и умножает на 100.
   2. Определение самой болезни: Параллельно вы пропускаете это же фото через классификатор — EfficientNet-B4, ResNet50 или ViT (Vision Transformer), который обучен на датасете болезней и выдает точный диагноз (например: «Альтернариоз, уверенность 96%»). [2, 3, 4] 

## Вариант Б: Комплексные репозитории на GitHub
На GitHub есть открытые проекты, созданные учеными специально для детекции болезней с оценкой степени тяжести:

* Crop-Disease-Detection-and-Severity-Estimation (на базе исследований PLOS ONE) — готовый пайплайн, сочетающий глубокое обучение для классификации и алгоритмы обработки изображений для подсчета процента поражения. [1] 
* YOLOv8 / YOLOv9 / YOLOv11 — если разметить датасет bounding box'ами (рамками) или масками, YOLO в реальном времени способна выдавать класс болезни и площадь её распространения. [4, 5]

## 2. Мультимодальный подход (Без кода)
Если вам нужно решение «здесь и сейчас» без обучения собственных моделей, лучше всего с этим справляются современные Vision-модели (Llama 3.2 Vision, GPT-4o, Claude 3.5 Sonnet). [6] 

* Вы можете отправлять фотографию листа по API и использовать структурированный промпт (Prompt Engineering):

«Проанализируй лист растения на фото. Верни строго JSON формат с полями: "plant_species" (вид растения), "disease_name" (название болезни на латыни/русском), "confidence" (уверенность в %), "damage_percentage" (процент поражения листа от 0 до 100) и "symptoms" (описание симптомов)».

* Модели вроде Llama 3.2 11B Vision отлично справляются с определением площади «на глаз» и выдают структурированный ответ. [6, 7]

## 3. Где взять данные для обучения (Датасеты)
Чтобы нейросеть понимала, где какая болезнь, вам понадобятся готовые наборы размеченных изображений:

   1. PlantVillage — самый популярный и огромный открытый датасет (более 54 000 фото). Содержит 38 классов здоровых и зараженных листьев (томаты, картофель, яблони и др.). Идеален для обучения классификатора болезней. [8, 9] 
   2. PlantDoc — датасет, в котором изображения размечены рамками (bounding boxes). Помогает модели находить конкретные очаги болезни на листе. [4] 
   3. Kaggle (запросы "Leaf Disease Segmentation") — там можно найти уже готовые датасеты с пиксельными масками пораженных участков для моделей сегментации (YOLO-seg/U-Net). [10] 

------------------------------
## Резюме: пошаговый план реализации
Если вы планируете разрабатывать собственное приложение:

   1. Возьмите YOLOv8-seg (для сегментации).
   2. Скачайте датасет с масками листьев и болезней на Kaggle.
   3. Обучите модель. На выходе вы получите детекцию класса (какая болезнь) и две маски, площади которых легко сопоставить в коде на Python через библиотеку OpenCV, чтобы выдать точный процент заражения. [5, 11]
